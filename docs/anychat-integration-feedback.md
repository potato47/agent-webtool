## 问题与本地实现

两个会话共享进程时，默认全局来源编号跨会话累积，清空会影响同一来源表。为每个会话创建 `createSourceContext(initial?)`，在 SDK 第二参数传入 `sources`；`snapshot()` 支持由调用方保存和恢复来源，旧全局 API 保持兼容。

缓存命中也登记当前会话来源，已取消的请求在缓存读取前拒绝。当前实现另已修复缓存容量只统计正文、遗漏标题字节的问题。使用约束与示例见 [README](../README.md)。
